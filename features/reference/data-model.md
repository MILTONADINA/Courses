# Data Model Reference

**Status:** Features 1–6 schema implemented. Feature 7 reads that schema and adds no tables or columns.

## Tables

### `users`

| Field | Rule |
|---|---|
| `id` | Auto-generated primary key |
| `firstName`, `lastName` | Required strings |
| `email` | Required unique string |
| `universityId` | Required string |
| `userName` | Required unique string, stored lowercase |
| `password` | Required bcrypt hash, excluded from default queries |
| `role` | Required `admin` or `student` |

### `sessions`

| Field | Rule |
|---|---|
| `id` | Auto-generated primary key |
| `token` | Required string: the JWT, or empty after logout |
| `email` | Required user email |
| `expirationDate` | Required date, 24 hours after creation |
| `userId` | Required foreign key to `users.id` |

### `semesters`

| Field | Rule |
|---|---|
| `id` | Auto-generated primary key |
| `semsterName` | Required string. Saved as sent; not trimmed. A whitespace-only name is rejected. Names are not unique |
| `startDate` | Required `DATEONLY` calendar date |
| `endDate` | Required `DATEONLY` calendar date |
| `createdAt`, `updatedAt` | Timestamps generated by the model |

### `courses`

| Field | Rule |
|---|---|
| `id` | Auto-generated primary key |
| `courseNumber` | Required string |
| `courseName` | Required string |
| `courseDescription` | Required string |
| `courseSemesters` | Required string. Text, not a foreign key to `semesters` |
| `courseFrequency` | Required string |
| `courseHours` | Required string |
| `courseDept` | Required string |
| `createdAt`, `updatedAt` | Timestamps generated by the model |

### `faculty`

| Field | Rule |
|---|---|
| `id` | Auto-generated primary key |
| `firstName` | Required string. Saved as sent; not trimmed |
| `lastName` | Required string. Saved as sent; not trimmed |
| `dept` | Required free-text string. Saved as sent; not trimmed |
| `createdAt`, `updatedAt` | Timestamps generated by the model |

The table name is `faculty` (not pluralized). A faculty member is not a user account and has no login or role.

### `sections`

| Field | Rule |
|---|---|
| `id` | Auto-generated primary key |
| `sectionNumber` | Required string. Saved as sent; not trimmed |
| `semesterId` | Required foreign key to `semesters.id`, `ON DELETE RESTRICT` |
| `courseId` | Required foreign key to `courses.id`, `ON DELETE RESTRICT` |
| `facultyId` | Required foreign key to `faculty.id`, `ON DELETE RESTRICT` |
| `daysOfWeek` | Required free-text string, for example `MWF`. Saved as sent; not trimmed |
| `startTime`, `endTime` | Required `TIME`, returned as `HH:MM` |
| `createdAt`, `updatedAt` | Timestamps generated by the model |

### `enrollments`

| Field | Rule |
|---|---|
| `id` | Auto-generated primary key |
| `sectionId` | Required integer foreign key to `sections.id`, `ON DELETE CASCADE` |
| `studentId` | Required integer foreign key to `users.id`, `ON DELETE CASCADE`; enrollment routes accept only authenticated students |
| `createdAt`, `updatedAt` | Timestamps generated by the model |

The unique index on `(studentId, sectionId)` prevents duplicate enrollments, including concurrent requests. Enrollment creation always takes the student id from the authenticated session; updates cannot change the owner. Deleting a section or student cascades to their enrollments without affecting other records. The new table is created by the application's existing Sequelize startup sync.

## Associations

One user has many sessions. Each session belongs to one user through `userId`. A semester, a course, and a faculty member each have many sections. Each section belongs to one semester (`semesterId`), one course (`courseId`), and one faculty member (`facultyId`). The Semester, Course, Faculty, and Section models are registered in `backend/app/models/index.js`.

A section and a student user each have many enrollments (`enrollments`). Each enrollment belongs to one section (`section`) and one student user (`student`). The Enrollment model and all four associations are registered in `backend/app/models/index.js`. Feature 7 uses those associations to list a student's courses. It does not add a table, a column, or an association.
